1. Assembly practice

Write the following programs in Hack assembly language. To test you programs, run them using the hardware simulator available from nand2tetris. You will need Java installed to run, but many of you will have Java already from other courses.

All assembly programs are in the asm directory.

  1. In the file, asm/ROFL.asm, write a program that writes the string ROFL to memory addresses 0 to 4 in RAM. The ASCII characters for ROFL are 82, 79, 70, and 76.

  2. In the file, asm/mult.asm, write a program that computes R2 = R0 * R1. R0, R1, and R2 correspond to the first three locations in memory. Because the ALU does not natively support multiplication, use repeated addition to compute the answer.

  3. In the file, asm/count_key.asm, write a program that increments a count, stored in R0, whenever the user presses a key

2. CPU

In the file, common/cpu.c, implement the function CPU::tick(). This function should implement the architecture from Figure 5.9 of The elements of Computing Systems. Extend the tests in test_cpu.c to check your implementation.

$ *make*

3.1. Interactive debugger

Under construction

In the file, hackdb.c, write a program that allows the user to set breakpoints and step through a program by instructions. While paused, the program can also print out the values of registers and memory.

$ make
$ ./hackdb
usage: hackdb 
$ ./hackdb add100.hack
hackdb> b 0
hackdb> r
Instruction 0: 0b 0000 0000 0001 1010 (0x001A) (26)
hackdb> n
hackdb> p A
A: 0b 0000 0000 0001 1010 (0x001A) (26)
hackdb> p M[0]
M[0]: 0b 0000 0000 0000 0000 (0x0000) (0)
hackdb> clr
cleared all breakpoints
hackdb> c
continuing
program has finished
hackdb> p M[0]
M[0]: 0b 0001 0011 1011 1010 (0x13BA) (5050)
hackdb> quit
$
Your homework uses the readline library to handle command line input and history.
